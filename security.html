Security

Last updated: June 18, 2026

Fleet operations data is sensitive — dispatch, location, compliance, and financial records. TekOmni LLC, operating the GoFleetAI platform, takes a defense-in-depth approach to protecting it.

Data Encryption

  • In transit: all traffic to and from the Service is encrypted with TLS.
  • At rest: data is stored on encrypted infrastructure, and sensitive credentials (such as integration tokens) are additionally encrypted at the application layer.

Access Controls

  • Role-based access control limits what each user can see and do within an account.
  • Authentication is required for every request; sensitive operations are scoped and audited.
  • Administrative access to production systems is restricted to authorized personnel.

Tenant Isolation

GoFleetAI is multi-tenant. Each customer's data is isolated by row-level security keyed to their business entity, so one fleet can never access another fleet's data.

Infrastructure

The Service runs on reputable cloud providers with managed, regularly patched infrastructure. Database backups and monitoring are in place to support availability and recovery.

Integrations

Connections to third-party systems (ELD/telematics, accounting, mapping, messaging) use scoped credentials stored encrypted. We request only the access needed to deliver the feature you enable.

Compliance Support

GoFleetAI is built to help carriers meet FMCSA Hours of Service, document, and inspection requirements. The platform supports your compliance program but does not replace your own legal and regulatory obligations.

Reporting a Vulnerability

If you believe you've found a security issue, please contact us so we can investigate promptly. Responsible disclosure is appreciated.
